# FolderFlow 2.2.0

- Automatic interface language: Chinese Windows UI selects Simplified Chinese; other Windows UI languages select English.
- Persistent System / English / Simplified Chinese selection, with immediate switching while idle.
- Localized task editing, mode and scope choices, inventory filters, progress, diagnostic display and user guide.
- Language changes leave task identifiers, source/destination paths, manifests and resume records unchanged.
- The selector is disabled during running tasks. Engine phases and stored status codes remain language-independent.
- Chinese and English demonstration screenshots and bundled user guides.

Keep `data/` and destination-side metadata when upgrading. Pause and close the old application before replacing its executable.
