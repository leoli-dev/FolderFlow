FolderFlow 2.3.1 — Windows 文件备份与同步
2026-10-08

开始使用
右上角 Language / 语言：默认跟随 Windows 界面语言，中文系统用简体中文，其他系统用英文。
可手动选择 English 或简体中文，空闲时立即切换并保存。任务运行期间暂时禁用切换。
界面语言不会改变任务编号、路径、文件名或断点记录；英文界面打开 USER_GUIDE.txt。
双击 FolderFlow.exe，无需安装 Python或以管理员身份运行。
新安装从空任务列表开始；已有配置会加载，不会自动扫描或复制。
1. 点击“新建任务”，命名任务，选择或填写来源、目标。
2. 选择任务模式，保存任务。
3. 选中任务，点击“分析 / 扫描”，查看新增、更新、无需复制和空间需求。
4. 点击“执行 / 继续”。程序重新扫描并复制，以处理分析后的来源改动。
5. 可暂停，或关闭程序请求安全暂停。再次运行同一任务可继续。
6. 重要备份完成后，点击“完整校验”，比对来源与目标的 SHA-256。

文件清单与进度
分析后在“文件清单”页查看全部已知文件及执行计划；默认筛选“待同步”。
可切换全部、已完成、失败和镜像回收，搜索相对路径，每页 200 项，支持页码跳转。
列表包括任务、相对路径、大小、新增/更新/无需复制/回收、状态与错误说明。
无法读取的目录/文件也会出现在失败筛选中；其容量未知，不计入已知文件总量。
复制/校验时标记当前文件；操作日志位于独立页。
总体进度以当前运行范围为准，包含以前已验证完成的文件；单文件进度独立显示。
总体按数据量计，复制、来源哈希、目标哈希贡献过程进度；正式副本发布后才记完成。
零字节文件按项目数计；镜像回收文件计入项目数，回收不计传输容量。
失败、暂停或最后整理未结束时，不显示成功 100%。扫描容量未知时显示活动进度。
“完整校验”的总体进度每轮从 0 开始，不复用之前已经复制的进度。
预计剩余时间是当前处理速度的估算，可能随大文件、校验、重试和小文件比例变化。
升级正在备份的旧版时，先暂停并关闭程序，再替换新版；保留 data/ 与目标元数据续传。

来源和目标
支持本机目录、移动硬盘、映射网络盘，以及 Windows SMB UNC 路径。
例如 C:\Users\Public\Documents、E:\Backups、\\server\share\folder。
目标没有盘符限制，也可填写尚未创建的完整文件夹路径。
使用当前 Windows 会话的权限和网络凭据，不保存密码；必要时先用资源管理器
连接共享目录。网络目标需有创建、写入、改名等相应权限。
不直接连接 SFTP/FTP、S3、WebDAV 或云服务 API；本机已挂载目录可作为路径使用。
新任务的副本直接位于目标目录，保留来源内部的文件夹结构。
目标中的 .folderflow\任务ID 保存临时文件、历史版本和回收文件；不要移动或编辑。
同一个来源可以建立多个任务，备份到不同目标。
来源和任何任务的目标不能互相包含；两个任务的目标也不能互相包含。
软件状态目录应放在来源之外；若要复制整块盘，请把软件放在另一块盘。
现有链接/junction/reparse point 不在复制范围；扫描会报告问题。

三种模式
版本备份：来源 → 目标。保留目标独有文件，每次替换前的副本保存为旧版本。
单向同步：来源 → 目标。复制新增和改动文件，保留目标独有文件。
          可自行选择是否保留替换前的旧版本；默认保留。
镜像同步：来源 → 目标。复制新增和改动文件，目标独有的文件移入回收区，
          多余空目录也保留恢复记录后移出。不会自动永久清理回收区。
          若来源扫描/复制有错误，或来源离线，不进行镜像回收。
过滤规则之外的目标文件保持原样。上述同步均为单向，不向来源回写文件。
本版本没有双向同步、冲突合并或删除向来源传播。

任务管理
可新建、编辑、复制、启用/停用或移除任务。移除任务只改变配置，不删除文件。
按 Ctrl 多选、Ctrl+A 全选。操作范围可选“选中任务”或“所有启用任务”。
分析、执行和完整校验只影响当前运行范围；其他任务的清单保留。
改变来源会建立新的清单身份；旧副本与历史记录保留，不复用旧校验结果。
改变目标会在新位置重新建立副本，旧位置不会自动清理。
更换来源后，请选择一个不同目标文件夹，避免与旧目标的来源绑定冲突。
任务不会自动定时运行；程序关闭后没有后台服务。

过滤与传输选项
包含：例如 *.jpg; *.png，仅包含符合规则的文件。留空包含所有普通文件。
排除：例如 *.tmp; cache/**; .git/**。排除目录时会跳过其整个子树。
模式使用通配符，多个规则用分号分隔；相对路径统一按 / 匹配。
规则不提供内容搜索或正则表达式。过滤会写入报告配置，便于确认备份范围。
保留空间：以 GiB 指定，可设 0；新任务默认 1 GiB，移动盘可按容量自行调整。
同一个目标卷的多个任务会合并需求，保留空间取这些任务中最大的值。
预检估算含文件/目录开销和版本占用，不抵扣临时文件，可能高估额外空间需求。
不同网络共享是否使用同一物理存储无法由路径确定；执行时也持续检查实际空闲量。
限速：以 MiB/s 指定，0 为不限制。控制复制数据流，校验读取不受此限速控制。
重试：可设重试次数及间隔；默认每 10 秒重试，最多 30 次。
Windows 网络读取若卡在系统超时中，暂停需要等待当前调用返回。

完整性和恢复
快速分析按来源大小和最后修改时间检测改动；完整校验读取两端所有入选文件，
能发现大小和时间未变化的内容修改。失败项目会被标记，下轮执行会重新复制。
先复制到临时文件，核对 NAS/磁盘来源与临时副本的 SHA-256，再发布正式副本。
续传前核对已有前缀；来源改变或前缀损坏时重新开始该文件。
来源在复制/校验过程中变化会报告错误，不计为校验完成。
旧版本、镜像回收文件和临时文件占用真实空间，不会自动清理。
点击“报告与版本记录”，查看 retained-versions.csv 中的原相对路径和存放位置。
恢复时从对应存放位置复制到你需要的目录；空目录记录以路径末尾的分隔符区分。
复制重要内容前可先另存副本，再决定是否覆盖现用文件。
恢复记录及清单保存在 data\manifest.sqlite；保留整个程序文件夹才能保留任务状态。

报告
reports\summary.json：本轮任务配置、范围、扫描统计与完整校验结果。
reports\file-manifest.csv：文件状态、目标、SHA-256 与校验时间。
reports\issues.csv：本轮任务的扫描、复制、校验问题。
reports\retained-versions.csv：旧版本、镜像回收文件/空目录及实际存放位置。
reports\source-missing-retained.csv：此前见过、本轮入选清单没有见到的文件。
data\activity.log：操作记录；data\diagnostics.log：异常诊断。
报告为最近一次运行范围的结果；文件名/内容不作为程序指令执行。

范围
这是普通文件主数据流和目录的备份，不提供系统镜像、Windows ACL/所有者、
备用数据流、系统/应用快照、符号链接复制或运行中数据库的一致性快照。
数据库等持续写入的数据，需要应用原生备份、导出或停写后复制。
文件逐项校验不是原子快照；要确认一个静止数据集，应停止写入后重新同步及校验。
目标文件按目标设备自身的权限和加密设置存储；程序不提供独立加密和密钥恢复。
文件系统自身的名称、路径、单文件大小等限制仍然适用，失败项目会列入报告。
软件不会修改磁盘分区、系统账户、权限、设备配置或格式化磁盘。

旧任务迁移
既有任务、清单和断点记录可保留。旧任务已有目标目录时，继续使用原先的
files 子目录与 _control 元数据结构；不要移动来改变结构。
全新的便携包不含任何个人来源、目标、任务或清单。
升级请保留 data；同一份目标不要同时用旧版和新版执行任务。

开发
src\folderflow\app.py：Windows 原生任务界面。
src\folderflow\engine.py：扫描、容量、复制、续传、版本、镜像回收和校验。
tests\：隔离测试。
在仓库根目录编译：powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1
构建步骤详见 docs\BUILD.md。

性能：编辑任务 → 性能与重试。扫描/分析并发 1–16（默认 4），传输并发 1–8（默认 1）。
大量小文件可先试传输 2–4；机械盘繁忙时使用 1。设置复制限速会按单线程执行。
并发仍执行来源和本地的 SHA-256 校验，任务和续传格式兼容旧版。
总体进度合计所有活跃文件；当前文件栏展示最近更新的一个文件。完整校验仍为串行。
