# FolderFlow 2.0.0

Portable Windows folder backup and one-way synchronization.

- Versioned backup, one-way update and recoverable mirror modes.
- Independent named tasks with local, removable, mapped and SMB paths.
- Resumable copying, SHA-256 verification, capacity preflight, glob filters, retries and transfer limits.
- Local durable state and CSV/JSON operation reports.
- Fresh release packages contain no personal configuration or runtime state.

Extract the portable ZIP and run `FolderFlow/FolderFlow.exe`. No installation or separate Python runtime is required.

This release does not include bidirectional synchronization, background scheduling, system imaging,
ACL/alternate-stream copying or application-consistent database snapshots.
